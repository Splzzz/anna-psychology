# Персональный сайт психолога Анны

Статический сайт на Astro и TypeScript. Главная знакомит с Анной, направлениями её работы и условиями онлайн-консультаций. В комплект входят три отдельные страницы документов. Шрифты, иллюстрации и фотографии загружаются с самого сайта.

## Локальный запуск

Используйте Node.js 22.12 или новее и npm. Выполните в папке проекта:

```sh
npm ci
npm run dev
```

Откройте локальный адрес, который напечатает Astro. В Windows при ограничениях PowerShell вместо `npm` можно использовать `npm.cmd`. Изменения исходников сразу видны в режиме разработки.

Проверка типов, сборка и просмотр версии для передачи хостингу:

```sh
npm run check
npm run build
npm run preview
```

Открывайте эту версию по адресу локального сервера. Пути к страницам и ресурсам рассчитаны на корень домена.

## Редактирование

| Что изменить | Файл |
| --- | --- |
| Имя, контакт, дополнительные ссылки, цены, скидка, продолжительность, подписи кнопок, домен и SEO | `src/data/site.ts` |
| Навигация, первый экран и шесть направлений работы | `src/data/home.ts` |
| Знакомство, подход, порядок встреч, условия, образование, FAQ и приглашение к записи | `src/data/content.ts` |
| Тексты проектов документов и их статус | `src/data/legal.ts` |
| Палитра, шрифты и общие элементы интерфейса | `src/styles/global.css` |
| Компоновка отдельных разделов | `src/components/` |

Для подключения записи задайте `site.contacts.primary` объект с полями `label` (название канала) и `href` (его подтверждённый адрес). После пересборки все кнопки записи будут открывать этот контакт. При значении `null` они открывают информационное окно о доступности записи. Дополнительные каналы задаются массивом `contacts.socials` в том же формате.

Обычная цена хранится в `pricing.regular`, скидка в процентах — в `pricing.discount`. Стоимость первой встречи рассчитывается автоматически. После изменения условий сверьте тексты документов и FAQ с фактическим порядком работы.

## Фотографии и оформление

Просмотрены все девять изображений в папке «Фото Анны» и пять референсов. Для первого экрана выбран `IMG_1030.JPG`: прямой взгляд и мягкий свет сохраняются при кадрировании на узком экране. В разделе «Давайте познакомимся» использован `IMG_1455.JPG` с Анной за столом на террасе. Снимки документов об образовании остались среди оригиналов.

В основе композиции — крупная антиква, воздушная сетка и мягкие синие оттенки из референсов. Портрет оформлен как фотокарточка на фоне авторской композиции со сгенерированным акварельным пейзажем. Темы консультаций сопровождаются небольшими контурными иллюстрациями. Анимации учитывают системное предпочтение уменьшенного движения.

Публикуемые копии портретов находятся в `src/assets/photos/`. Размеры — 480, 720 и 960 пикселей по ширине, пропорции 3:4. На сайте используются адаптивный WebP и запасной JPEG. Для замены подготовьте копии новых фотографий без EXIF, обновите их описания в `Hero.astro`, `Details.astro` и метаданные в `Base.astro`. Если меняются пропорции, обновите атрибуты размеров.

Гарнитуры Cormorant Garamond и Manrope поставляются локально. Лицензии OFL включены в `public/licenses/`.

## Публикация на российском хостинге

1. Подтвердите правовые тексты, данные исполнителя, порядок записи, оплаты, переноса и возврата. Перечень открытых вопросов находится в [LEGAL_CHECKLIST.md](LEGAL_CHECKLIST.md).
2. Выберите хостинг и домен, настройте HTTPS и проверьте фактическую обработку серверных журналов. Для этой версии достаточно обслуживания статических файлов.
3. Подключите подтверждённый контакт и задайте в `site.seo.origin` полный HTTPS-адрес домена. После пересборки появятся абсолютные canonical, ссылки Open Graph и адрес главной в карте сайта. Пока домен пуст, страницы содержат `noindex`, а `robots.txt` закрывает обход.
4. Выполните `npm ci`, `npm run check` и `npm run build`. Загрузите **содержимое папки `dist/`** в веб-корень. На сервере должны оказаться `index.html`, `_astro/`, `privacy/`, `consent/`, `terms/`, `licenses/`, `favicon.svg`, `robots.txt`, `sitemap.xml` и при использовании Apache файл `.htaccess`. Исходные фотографии и папка референсов остаются на компьютере.
5. Настройте выдачу `index.html` для путей каталогов. Для ресурсов `/_astro/` с хешем в имени задайте `Cache-Control: public, max-age=31536000, immutable`, для HTML, XML и TXT — `no-cache`. Файл `.htaccess` содержит эти правила для Apache с разрешёнными директивами. В Nginx их нужно задать на уровне конфигурации сервера.
6. Проверьте главную, три документа, ссылки записи, `robots.txt` и `sitemap.xml` непосредственно на рабочем домене. Черновики документов изначально исключены из индекса.

## Персональные данные и аналитика

Первая версия работает без формы, CRM, приёма оплаты, аналитических скриптов и необязательных cookie. Переписка для записи происходит в настроенном канале. До его подключения посетитель может только ознакомиться с условиями.

Если позднее понадобится аналитика, сначала уточните цели, провайдера, состав данных, необходимость согласия и обновите политику. Общая точка подключения — `src/layouts/Base.astro`. Когда согласие требуется, загрузчик должен запускаться после положительного выбора посетителя и учитывать отзыв. Добавление формы потребует отдельного решения для серверной обработки, хранения и удаления заявок.
