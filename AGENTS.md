
# Проект: сайт-визитка психолога Анны

## Назначение
- Сайт психолога с преимущественно онлайн-консультациями для клиентов по всей России.
- Тон коммуникации: бережный, ясный, профессиональный, без давления и обещаний гарантированного результата.
- Основные темы: тревога, панические атаки, навязчивые мысли, поддержка и психологическое консультирование.

## Технологии
- Сохраняй существующую архитектуру Astro, HTML, CSS и JavaScript.
- Используй имеющиеся компоненты, стили и дизайн-токены; не вводи новую UI-библиотеку без необходимости.
- По возможности сохраняй статическую сборку Astro; не добавляй серверные зависимости без задачи, которая их требует.

## Дизайн и UX
- Придерживайся спокойной пастельной палитры, мягких небесных оттенков и умеренных анимаций.
- Сохраняй читабельность, контрастность и корректную работу на мобильных экранах.
- Для анимаций учитывай `prefers-reduced-motion`.
- Не изменяй не относящиеся к заданию блоки и тексты.

## Контент и техническое качество
- Не придумывай образование, квалификации, отзывы, цены или контакты психолога: используй только подтверждённые данные.
- Поддерживай семантическую HTML-разметку, SEO-заголовки и описания, а также доступность форм.
- Если добавляется форма заявки, не собирай лишние персональные данные; вопросы обработки данных и юридические тексты отмечай для проверки владельцем проекта.
- После изменений запускай доступные проверки Astro и сборку, если это возможно.
